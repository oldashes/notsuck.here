# notsuck.here

Vibe-coded toys that actually work — small WebGL games and demos, live at https://notsuck.here

## How it works

- Static site, hosted on GitHub Pages.
- Custom domain `notsuck.here` via the `CNAME` file.
- Each toy lives in its own folder; the homepage links them all.

## Add a toy

1. Drop the game files in a new folder, e.g. `my-game/`.
2. Add a card for it on `index.html`.
3. Push — the site rebuilds automatically.
